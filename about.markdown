I made this website with Jekyll as I wanted something simpler than Astro. While I think Astro is great, for a personal website with a blog, Jekyll is _perfect_.

I made this site to be able to share my projects and blog posts in one place. And an upside to using Jekyll is Github Pages support so I can get a very nice github.io domain for free.
